# Selfie Check Feedback — MANDATE

## Integration Flow
Selfie Check is the fastest path to a low-friction charter experience. It works well for demos and lower-value budgets, especially when the goal is to reward quick human verification while keeping trust assumptions explicit.

## Developer Portal Navigation
The flow is approachable, but the threshold and budget logic should be called out earlier in the docs so teams can design the right tiering strategy from the start.

## Sandbox App
The sandbox flow is strong for liveness and verification testing, but a clearer visual distinction between Selfie Check and Orb Verified totals would reduce confusion.

## Issues Found
- Budget ceilings for Selfie Check need clear validation against the smart contract rules.
- Reuse checks on the same person/domain can be confusing without a clear explanation in the onboarding flow.
- The user experience would improve if the app clearly explained the risk profile of each verification level.

## What Was Missing
- A simple comparison matrix for Selfie Check vs. Orb across budget, speed, and trust expectations.
- More examples of domain-specific charter limits.
- Better sandbox guidance for user test states and how to simulate multiple sessions.
